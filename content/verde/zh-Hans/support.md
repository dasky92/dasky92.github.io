# 技术支持

## 联系我们

如有问题、错误报告或建议，请通过以下方式联系：

- **电子邮箱：** 1621829808@qq.com
- **GitHub Issues：** https://github.com/dasky92/dasky92.github.io/issues

应用内反馈入口暂未开放，请使用以上渠道。

GitHub Issues 为**公开**页面，请勿发布敏感个人信息。联系时请附上设备型号、iOS 版本和应用版本，以便我们更快回复。

## 导入音乐

前往 **设置 → 导入**，从「文件」App 或 iCloud 云盘选择音频文件。

支持的格式包括 MP3、FLAC、AAC、M4A、WAV、OGG、Opus、ALAC 和 AIFF。

## Wi-Fi 传输

在设置中开启 **Wi-Fi 传输**，从同一局域网内的电脑上传歌曲。

上传时请保持本应用停留在设置页面。离开设置后传输会自动停止。

## 从其他 App 分享

在「文件」、Safari 或其他 App 中点击 **分享**，选择 Verde 将音频复制到曲库。

也可在分享菜单的 **打开方式** 中选择 Verde 打开音频文件。

## 喜欢的歌曲

在播放器中点击心形图标，将歌曲保存到 **喜欢** 列表。

## 播放与曲库

- 在曲库标签页按 **歌曲** 或 **艺术家** 浏览。
- 使用 **搜索** 查找艺术家与歌曲。
- 支持顺序、随机与单曲循环播放模式。
- 播放时支持锁定屏幕与控制中心控制。
