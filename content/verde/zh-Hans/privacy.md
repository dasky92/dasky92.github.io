# 隐私政策

## 概述

Verde Player（以下简称「本应用」）是一款离线优先的音乐播放器。播放、曲库管理、喜欢歌曲与播放历史均在您的设备上运行。我们不托管、不流媒体传输、也不提供任何音乐内容。

本隐私政策说明我们是谁、处理哪些信息（如有）、何时处理以及您有哪些选择。

## 我们是谁

本应用的数据控制者为个人开发者 **dasky92**，常住于中华人民共和国山西省。

如有隐私相关问题或请求，请通过下文「联系我们」与我们取得联系。

## 适用范围

本隐私政策适用于全球范围内的本应用用户，法律另有规定的除外。

本应用在 Apple App Store 的年龄分级为 **4+**，面向一般受众。本政策并不要求您达到最低年龄方可使用本应用的设备端功能；涉及儿童的信息处理请参见「儿童隐私」。

## 我们收集的信息

我们尽可能减少数据收集。根据您如何使用本应用，可能适用以下情形：

**1. 本地使用（无需账号）。** 当您离线使用本应用时，我们不会向服务器收集或传输个人信息。您的音乐文件、元数据、播放历史、喜欢歌曲与偏好设置均保存在您的设备上。

**2. 由本应用发起的技术性网络连接。** 在有限情形下，本应用可能在您未主动输入个人信息的情况下连接互联网，例如：

- 通过 Apple App Store 检查或下载应用更新；
- 从 GitHub Pages 获取公开发布的法律文档（如本政策）。

上述请求属于技术性请求。我们不会借此建立您的用户画像，也不会通过这些请求获取您的姓名、电子邮箱或曲库内容。

**3. 您主动联系时自愿提供的信息。** 若您选择发送邮件或打开 GitHub Issue，我们仅会收到您主动提供的内容（例如电子邮箱、消息文本、您选择附上的设备信息或截图）。GitHub Issues 为**公开**页面，请勿发布敏感个人信息。

**Wi-Fi 传输。** 当您开启 Wi-Fi 传输时，本应用使用本地网络接收同一局域网内电脑上传的音乐文件。传输过程中不会向我们的服务器发送曲库数据。

**WebDAV 导入（可选）。** 若您在「来源」中添加 WebDAV 服务器，本应用将连接**您自行配置的服务器**（例如家用 NAS 或提供 WebDAV 的服务）以浏览并下载音频至本地曲库。服务器地址、用户名与密码保存在您的设备上（凭证存于 Keychain）。下载的文件保留在本机，不会上传至我们的服务器。我们不运营该 WebDAV 服务器，也不会通过此功能获取您的服务器凭证或曲库内容。使用局域网 HTTP 时，需在应用内明确同意。

**Scrobbling（可选，默认关闭）。** 若您在「设置」中开启 Scrobbling 并登录 Last.fm 或 ListenBrainz，本应用会将您所听曲目的艺术家、曲名、专辑与播放时间戳发送至所选服务。仅当 Scrobbling 处于开启且您已登录时才会发送。网络不可用时，scrobble 会暂存于您的设备并在之后发送。我们不会向这些服务共享其他数据（曲库内容、文件或标识符）。您可随时在「设置」中关闭 Scrobbling；各服务方的隐私实践请参见「第三方服务」。

我们不集成第三方分析、广告或跟踪 SDK。

## 我们如何使用信息

- **设备上的数据**仅用于提供应用功能（播放、曲库整理、搜索、喜欢与历史记录）。
- **您自愿发来的联系信息**（邮件或 GitHub Issues）仅用于回复您、排查问题与改进本应用。

我们不会将您的数据用于广告、用户画像或出售给第三方。

## 处理的法律依据（欧洲经济区与英国）

若您位于欧洲经济区或英国，我们基于以下法律依据处理个人信息：

- **履行合同 / 合法利益：** 提供您请求的本应用设备端功能。
- **同意 / 合法利益：** 回复您主动发送的消息。
- **法律义务：** 在适用法律要求时保留或披露信息。

在基于同意进行处理时，您可随时撤回同意，不影响撤回前处理的合法性。

## 数据存储与保留

- 音乐与曲库数据保留在您的设备上，直至您删除或卸载本应用。
- 您发送给我们的联系记录仅在处理您的请求及维持合理支持记录所需的期限内保留，法律要求更长期限的除外。

## 第三方服务

- **Apple App Store** 根据 [Apple 隐私政策](https://www.apple.com/legal/privacy/) 处理购买、更新及相关账户交互。
- **GitHub Pages** 托管我们公开的法律文档。本应用可能下载这些文件；我们不会通过该下载获取您的个人数据。
- 若您使用 GitHub Issues，**GitHub** 将根据 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement) 处理您提交的信息。
- **Last.fm**（CBS Interactive）。当您开启 Scrobbling 并登录 Last.fm 时，您的收听数据将发送至 Last.fm 服务器，用于个人收听统计与推荐。Last.fm 对该数据的使用受 [Last.fm 隐私政策](https://www.last.fm/legal/privacy) 约束。此功能为可选，可在「设置」中关闭。
- **ListenBrainz**（MetaBrainz Foundation）。当您开启 Scrobbling 并登录 ListenBrainz 时，您的收听数据将发送至 ListenBrainz 服务并公开存储（您可将个人资料设为私有）。ListenBrainz 对该数据的使用受 [MetaBrainz 隐私政策](https://metabrainz.org/privacy) 约束。此功能为可选，可在「设置」中关闭。

## 儿童隐私

本应用在 App Store 的分级为 **4+**。我们不会通过本应用故意收集儿童的个人信息。

由于核心功能在本地运行且无需账号，在正常设备端使用过程中，我们不会有意收集包括儿童在内的任何人的个人信息。

**请勿让儿童在未经父母或监护人同意的情况下通过邮件或 GitHub Issues 联系我们。** 若您认为儿童在未经适当同意的情况下向我们提供了个人信息，请联系我们，我们将采取合理措施予以删除。

就美国用户而言，根据《儿童在线隐私保护法》（COPPA），我们不会故意收集 **13** 岁以下儿童的个人信息。
