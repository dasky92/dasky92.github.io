# Политика конфиденциальности

## Обзор

EyesProtector («Приложение») — **тренер привычек** при зрительной усталости и **спутник очков для близи** для Mac, iPhone и iPad. Помогает держать паузы вдаль, напоминать о смене очков при двух парах и вести субъективный дневник. Приложение **не** является медицинским изделием и **не** заменяет диагностику, лечение или профессиональный уход.

Политика объясняет, кто контролёр, какие данные обрабатываются, как связаны опциональная синхронизация **iCloud** и **платные** функции, и какие у вас есть выборы. Основной цикл работает на устройстве без аккаунта у нас.

## Какие данные обрабатываем

### 1. Использование на устройстве (по умолчанию)

Без синхронизации обычно остаются на устройстве и **не** загружаются на наши серверы (своего бэкенда аккаунтов нет):

- расписания пауз, рабочие часы, пауза / конец дня / отключение на сегодня;
- схема очков и связанные настройки;
- Smart Pause (фокус, список приложений на переднем плане на Mac);
- дневник ощущений и история выполнения;
- внешний вид и прочие локальные настройки.

### 2. Опциональная синхронизация iCloud

При включении **iCloud Sync** выбранные данные могут синхронизироваться между устройствами с **одним Apple ID** через **Apple iCloud**. Хостинг — у **Apple**. Мы не ведём отдельную облачную БД дневника и не можем войти в ваш iCloud.

### 3. Разрешения

Уведомления; статус Фокусирования (где доступно); сведения о приложении на переднем плане на Mac — только для списка, который вы добавили.

### 4. Технические соединения

Обновления App Store, покупки через Apple, публичные юридические страницы на GitHub Pages, iCloud при включённой синхронизации. Не для рекламных профилей.

### 5. Добровольные сообщения

Только то, что вы отправите по email или в публичный GitHub Issue.

### 6. Чего мы не делаем

Нет обязательного телефона / соцлогина для ядра; нет камеры для лица / внимания; в этой версии нет сторонних рекламных / аналитических SDK для межприложенного трекинга; **не продаём** персональные данные.

## Покупки и биллинг Apple

Предполагаемая модель (SKU и цены — на странице App Store):

- **Mac:** основной цикл бесплатен;
- **iPhone / iPad:** разовая покупка разблокирует основной цикл;
- **iCloud sync:** опционально и **без** отдельной платы при наличии iCloud;
- **темы часов паузы:** после разблокировки тема «双眼» бесплатна; другие могут быть разовыми покупками. На Mac часов нет.

Оплату обрабатывает **Apple**. Полный номер карты мы не получаем. Восстановление покупок — в приложении.
