# 隐私政策

## 概述

EyesProtector（以下简称「本应用」）是面向 Mac、iPhone 与 iPad 的视疲劳**习惯教练**与近用镜**工作流伴侣**。本应用帮助您在工作时段保持远眺节奏，可选支持双镜通勤换镜提醒，并允许记录主观酸胀评分。

本应用**不是**医疗器械，**不**提供诊断、治疗，也不替代专业验光或眼科服务。

本隐私政策说明我们是谁、处理哪些信息、可选的 **iCloud** 同步与**付费**能力如何涉及隐私，以及您有哪些选择。我们以「尽量少收集」为原则：核心习惯循环可在本机完成，无需向我们注册账号。

## 我们是谁

隐私相关问题或权利请求，请通过下文「联系我们」与我们取得联系。

## 适用范围

本政策适用于本应用的全球用户（当地法律另有要求的除外）。

本应用拟通过 Apple App Store 以健康与健身 / 习惯类定位分发。年龄分级以 Apple 审核结果为准（预期为一般受众，例如 4+；并非以儿童为主要服务对象）。

## 我们处理的信息

我们尽可能减少收集。视您如何使用本应用，可能涉及以下情形。

### 1. 本地使用（默认；无需向我们注册）

在未开启同步时，下列信息通常仅保存在您的设备上，**不会**上传到我们自建的服务器（我们也不运营自建账号后端）：

- 远眺安排、工作时段、休息暂停 / 下班模式 / 当日关闭等状态
- 配镜方案（单镜 / 双镜）及相关提醒偏好
- 智能暂停偏好（例如专注模式开关、Mac 前台 App 列表）
- 症状 / 酸胀日记（评分与可选备注）与远眺依从记录
- 外观及其他本地设置

卸载本应用后，本机应用数据通常会一并清除（具体以操作系统为准）。

### 2. 可选的 iCloud 同步（默认关闭，需您主动开启）

若您在本应用中开启 **iCloud 同步**：

- 相关设置、提醒相关状态、症状日记等习惯数据，可能经 **Apple iCloud** 在登录**同一 Apple ID** 的设备之间同步（例如本应用使用的 iCloud 键值 / Apple 提供的同步机制）。
- 同步由 **Apple** 提供与托管。我们**不**在自有服务器上另建一份您的日记库，也**无法**登录您的 iCloud 账号读取同步内容。
- 在本应用中**关闭**同步后，本应用侧将停止新的同步；本机通常仍保留本地副本。已存在于 iCloud 中的副本，其保留与删除受 **Apple** 的 iCloud 机制约束（系统设置 / 设置 → [您的姓名] → iCloud，以及 Apple 帮助文档）。
- iCloud 是否可用、容量与地区能力由 Apple 及您的 Apple ID / 店面决定。

请同时参阅 [Apple 隐私政策](https://www.apple.com/legal/privacy/) 与 iCloud 相关条款。

### 3. 您授予的系统权限与能力

在您授权（或系统向本应用开放）的前提下，本应用可能使用：

- **通知** — 用于远眺或其他习惯提醒
- **专注状态**（如系统提供）— 以便智能暂停在专注开启时搁置提醒
- **Mac 前台应用信息** — 仅用于匹配您加入智能暂停列表的 App（例如会议类 App）

您可在系统设置中撤销授权。拒绝授权可能影响对应功能，其余功能仍可使用。

### 4. 技术性网络连接

本应用或您的设备可能在您未向我们托管的表单填写个人信息的情况下联网，例如：

- 通过 **Apple App Store** 检查或下载更新
- 通过 Apple 完成**内购 / 订阅**（如已提供）
- 从 **GitHub Pages** 获取公开托管的法律文档（如本政策）
- 在开启同步时与 **Apple iCloud** 通信

我们不会利用上述连接为您建立广告画像。

### 5. 您主动提供的信息

若您发送邮件或提交 GitHub Issue，我们仅收到您选择提供的内容（例如邮箱、正文、设备信息、截图）。**GitHub Issue 为公开内容**，请勿提交敏感个人或健康细节。

### 6. 我们不会做的事

- 核心循环不要求手机号 / 微信 / 社交账号登录
- 不使用摄像头做人脸或注意力检测
- 本版本未集成用于跨 App 追踪的第三方广告或分析 SDK
- 我们**不出售**您的个人信息

## 购买、订阅与 Apple 计费

若 App Store 页面提供**付费**能力（例如将多设备 **iCloud 同步**作为订阅或一次性内购）：

- **Apple** 按 Apple 条款处理支付、收据与退款。我们不会收到您的完整银行卡号。
- Apple 可能向本应用提供有限的购买 / 权益状态（例如订阅是否有效），以便解锁付费功能。
- 请在 Apple ID 的订阅管理中取消或变更订阅；退款遵循 Apple 流程及适用法律。

免费核心能力（远眺节奏与搁置、配镜方案、本地日记）拟在**无需**购买同步的情况下可用。具体商品与价格以 App Store 产品页为准，可能因国家或地区而异。
