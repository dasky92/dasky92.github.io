入手

Mac は無料、スマホは一度の購入

無料

Mac

What's new

0.5.3 の新機能

机の遠望クロック、本機に合わせたスマート一時停止、6 言語の UI。

新

遠望クロック

解除済みの iPhone / iPad を机に置き、前面の遠望タイマーに。作業時間と完了度は主循環と共通。最初のテーマ「双眼」は無料、ほかは別購入。Mac はメニューバーのみでクロックはありません。

新

Mac のスマート一時停止

その Mac にある集中モードに合わせて一時停止（初期状態で「仕事」はオフ）。一時停止アプリは自分で追加し、会議アプリの初期リストはありません。iPhone / iPad は集中モードでは一時停止しません。

新

メニューバー、Dock なし

Mac はメニューバーに常駐。ウィンドウを閉じても、そこからまた開けます。

新

6 言語

アプリ UI はシステムに従い、英語・簡体字中国語・日本語・韓国語・ロシア語・スペイン語。本サイトも対応します。

新

iPhone と iPad

同じ四つのタブ。iPad の下ナビは左右スワイプ。設定に端末別の使い方。体感メモには短い語を足せます。

中核

続けていること

ブルーライトフィルターも、近視を治す訓練もしません。近い作業の日を続けやすくするだけです。

  • 作業時間の遠望

    やわらかい、または厳格な知らせ。休憩一時停止、退勤モード、当日オフで保留できます。

  • 配鏡と掛け替え

    単眼は掛け替えを出しません。二重眼鏡は通勤のタイミングで近用の流れを知らせます。

  • 足りる範囲のスマート一時停止

    Mac ではオンにした集中モードと、自分で追加した前面アプリ。手動の一時停止も。

  • 体感日記と完了度

    退勤前に 0–10 と短い語。遠望の完了は日ごと、枠ごとに見返せます。
