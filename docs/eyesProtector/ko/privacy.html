EyesProtector Version 1.1.0 시행일: 2026-09-30

개요

EyesProtector(“앱”)는 Mac / iPhone / iPad용 눈 피로 습관 코치이자 근용 안경 워크플로 동반자입니다. 근무 시간 원거리 보기, 이중 안경 교체 안내, 주관적 체감 기록 등을 돕습니다. 앱은 의료기기가 아니며 진단·치료·전문 진료를 대체하지 않습니다.

이 방침은 관리자, 처리 정보, 선택적 iCloud 동기화와 유료 기능, 선택지를 설명합니다. 핵심 순환은 저희 계정 없이 기기에서 동작하도록 설계되었습니다.

관리자

관리자는 중화인민공화국에 소재한 개인 개발자 dasky92입니다. 문의는 아래 연락처로.

적용 범위

현지법이 달리 요구하지 않는 한 전 세계 사용자에게 적용됩니다. App Store의 건강 및 피트니스 / 습관 위치 설정을 전제합니다. 연령 등급은 Apple 심사를 따릅니다(아동 대상 아님).

처리하는 정보

1. 기기 내 사용(기본, 저희 계정 없음)

동기화를 끈 경우 다음이 보통 기기에 남고 저희가 운영하는 서버로 올라가지 않습니다:

  • 원거리 일정, 근무 시간, 일시정지 / 퇴근 / 오늘 끄기
  • 배경 방안과 관련 설정
  • 스마트 일시정지(집중 토글, Mac 전면 앱 목록 등)
  • 체감 일기와 원거리 완료 기록
  • 모양 등 로컬 설정

2. 선택적 iCloud 동기화(기본 끔)

iCloud 동기화를 켜면 선택한 설정·알림 상태·체감 일기 등이 같은 Apple ID 기기 사이에서 Apple iCloud로 동기화될 수 있습니다. 호스팅은 Apple입니다. 저희는 별도 클라우드 DB를 두지 않으며 iCloud에 로그인해 내용을 읽을 수 없습니다.

3. 권한과 시스템 기능

알림, (가능한 경우) 집중 상태, Mac 전면 앱 정보(직접 추가한 일시정지 목록 일치용)를 쓸 수 있습니다. 시스템 설정에서 철회할 수 있습니다.

4. 기술적 연결

App Store 업데이트, Apple 내구입, GitHub Pages의 공개 법률 문서, 동기화 시 iCloud. 광고 프로필에는 쓰지 않습니다.

5. 자발적 제공

이메일이나 공개 GitHub Issue에 적은 내용만 받습니다. Issue는 공개입니다.

6. 하지 않는 일

핵심에 전화/SNS 로그인 불필요. 카메라 얼굴·주의 감지 없음. 본 버전에서 크로스앱 추적용 제3자 광고/분석 SDK 없음. 개인정보 판매 없음.

구매와 Apple 결제

상업 모델(SKU·가격은 지역 App Store 제품 페이지):

  • Mac: 핵심 순환 무료
  • iPhone / iPad: 일회 내구입으로 핵심 순환 잠금 해제
  • iCloud 동기화: 선택, iCloud가 있으면 별도 요금 없음
  • 원거리 시계 테마: 잠금 해제 후 「双眼」 무료, 추가 테마는 별도 일회 구매일 수 있음. Mac에는 시계 없음

결제는 Apple이 처리합니다. 전체 카드 번호는 받지 않습니다. 앱에서 구매 복원, 환불은 Apple 절차.
