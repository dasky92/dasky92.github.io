FAQ

근시를 치료하거나 조절력을 회복하나요?

아니요. EyesProtector는 습관 알림과 근용 안경 워크플로 동반자이며 의료기기가 아니고 검안을 대체하지 않습니다.

원거리 보기 전체 끄기가 없는 이유는?

원거리 보기는 근무 시간에 돌아가도록 설계되었습니다. 휴식 일시정지, 퇴근 모드, 오늘 끄기로 보류하세요.

무료와 유료는?

  • Mac: 핵심 순환 무료.
  • iPhone / iPad: 한 번 잠금 해제로 휴대폰·태블릿 핵심 순환.
  • iCloud 동기화: iCloud가 있으면 무료.
  • 원거리 시계: 잠금 해제 후. 「双眼」 테마 무료, 추가 테마는 별도 구매. Mac에는 시계 없음.

상품과 가격은 해당 지역 App Store 제품 페이지를 보세요.

구매와 환불은?

구매는 Apple을 통합니다. 앱의 구매 복원과 Apple 환불 절차를 따르세요.

iCloud 동기화가 실패하거나 스위치가 돌아가나요?

  1. 설정 → Apple ID → iCloud 로그인(App Store만이 아님).
  2. 계정·지역에서 iCloud 사용 가능 여부 확인.
  3. 앱 동기화를 끄고 다시 켜기.
  4. 실패 시 반열림을 피하려고 스위치를 되돌립니다.

자체 서버에서 iCloud 내용을 읽을 수 없습니다. 개인정보 처리방침 참고.

스마트 일시정지가 안 되나요?

  • 집중 모드 일시정지는 Mac만. 이 Mac에 있는 집중만 표시. 「업무」는 기본 끔.
  • 전면 앱 일시정지도 Mac만. 목록은 비어 있고 직접 추가.
  • iPhone / iPad는 집중으로 일시정지하지 않음.

원거리 시계가 없나요?

잠금 해제된 iPhone / iPad가 필요합니다. 「双眼」은 무료로 열립니다. Mac에는 없습니다.

알림이 없나요?

시스템 설정에서 알림을 허용하세요. 보류 모드는 의도적으로 알림을 막습니다.

엄격 모드를 못 나가나요?

화면 조작 또는 Mac 메뉴 막대를 사용하세요. 강제 종료 후 다시 여세요.
