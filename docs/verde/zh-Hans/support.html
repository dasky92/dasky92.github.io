联系我们

如有问题、错误报告或建议，请发送邮件至 1621829808@qq.com。

您也可以在应用内通过 设置 → 帮助与反馈 提交（在功能开启时）。

请附上设备型号、iOS 版本和应用版本，以便我们更快回复。

导入音乐

前往 设置 → 导入，从「文件」App 或 iCloud 云盘选择音频文件。

支持的格式包括 MP3、FLAC、AAC、M4A、WAV、OGG、Opus、ALAC 和 AIFF。

Wi-Fi 传输

在设置中开启 Wi-Fi 传输，从同一局域网的电脑上传歌曲。

上传时请保持应用停留在设置页面。离开设置后传输将自动停止。

从其他 App 共享

在「文件」、Safari 或其他 App 中点 共享，选择 Verde 即可将音频复制到曲库。

也可通过共享菜单的 打开方式 用 Verde 打开音频文件。

喜欢的歌曲

在播放器中点按心形图标，即可将歌曲保存到 喜欢 收藏。

播放与曲库

  • 在「曲库」标签页按 歌曲 或 艺人 浏览。
  • 使用 搜索 查找艺人名与歌曲名。
  • 支持顺序播放、随机播放与单曲循环。
  • 播放时支持锁屏与控制中心的播放控制。
