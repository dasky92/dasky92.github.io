隐私政策

Verde Player Version 1.1.0 生效日期: 2026-07-07

概述

Verde Player（以下简称「本应用」）是一款离线优先的音乐播放器。播放、曲库管理、喜欢歌曲与播放历史均在您的设备上运行。我们不托管、不流媒体传输、也不提供任何音乐内容。

本隐私政策说明我们是谁、处理哪些信息（如有）、何时处理以及您有哪些选择。

我们是谁

本应用的数据控制者为个人开发者 dasky92，常住于中华人民共和国山西省。

如有隐私相关问题或请求，请通过下文「联系我们」与我们取得联系。

适用范围

本隐私政策适用于全球范围内的本应用用户，法律另有规定的除外。

本应用在 Apple App Store 的年龄分级为 4+，面向一般受众。本政策并不要求您达到最低年龄方可使用本应用的设备端功能；涉及儿童的信息处理请参见「儿童隐私」。

我们收集的信息

我们尽可能减少数据收集。根据您如何使用本应用，可能适用以下情形：

1. 本地使用（无需账号）。 当您离线使用本应用时，我们不会向服务器收集或传输个人信息。您的音乐文件、元数据、播放历史、喜欢歌曲与偏好设置均保存在您的设备上。

2. 由本应用发起的技术性网络连接。 在有限情形下，本应用可能在您未主动输入个人信息的情况下连接互联网，例如：

  • 通过 Apple App Store 检查或下载应用更新；
  • 从 GitHub Pages 获取公开发布的法律文档（如本政策）。

上述请求属于技术性请求。我们不会借此建立您的用户画像，也不会通过这些请求获取您的姓名、电子邮箱或曲库内容。

3. 您主动联系时自愿提供的信息。 若您选择发送邮件或打开 GitHub Issue，我们仅会收到您主动提供的内容（例如电子邮箱、消息文本、您选择附上的设备信息或截图）。GitHub Issues 为公开页面，请勿发布敏感个人信息。

Wi-Fi 传输。 当您开启 Wi-Fi 传输时，本应用使用本地网络接收同一局域网内电脑上传的音乐文件。传输过程中不会向我们的服务器发送曲库数据。

我们不集成第三方分析、广告或跟踪 SDK。

我们如何使用信息

  • 设备上的数据仅用于提供应用功能（播放、曲库整理、搜索、喜欢与历史记录）。
  • 您自愿发来的联系信息（邮件或 GitHub Issues）仅用于回复您、排查问题与改进本应用。

我们不会将您的数据用于广告、用户画像或出售给第三方。

处理的法律依据（欧洲经济区与英国）

若您位于欧洲经济区或英国，我们基于以下法律依据处理个人信息：

  • 履行合同 / 合法利益： 提供您请求的本应用设备端功能。
  • 同意 / 合法利益： 回复您主动发送的消息。
  • 法律义务： 在适用法律要求时保留或披露信息。

在基于同意进行处理时，您可随时撤回同意，不影响撤回前处理的合法性。

数据存储与保留

  • 音乐与曲库数据保留在您的设备上，直至您删除或卸载本应用。
  • 您发送给我们的联系记录仅在处理您的请求及维持合理支持记录所需的期限内保留，法律要求更长期限的除外。

第三方服务

  • Apple App Store 根据 Apple 隐私政策 处理购买、更新及相关账户交互。
  • GitHub Pages 托管我们公开的法律文档。本应用可能下载这些文件；我们不会通过该下载获取您的个人数据。
  • 若您使用 GitHub Issues，GitHub 将根据 GitHub 隐私声明 处理您提交的信息。

国际数据传输

我们位于中华人民共和国。若您在境外联系我们，您提供的信息可能在中国及我们使用的邮件或 GitHub 服务提供商所在国家/地区被处理。在法律要求时，我们将根据具体情况采取合理的保障措施。

您的权利与选择

根据您所在地区，您可能有权：

  • 访问、更正或删除我们持有的、来自您自愿联系的个人信息；
  • 限制或反对特定处理；
  • 在适用时要求数据可携带；
  • 向监管机构投诉（见「欧洲经济区与英国用户」）。

如需行使上述权利，请发送邮件至 1621829808@qq.com。我们可能需要核实您的请求。

您可以在不联系我们、不提交个人信息的情况下使用本应用。

欧洲经济区与英国用户

若您位于欧洲经济区或英国，您享有上述权利，并可向当地数据保护机构投诉。

我们力争在 30 天内回复隐私请求，具体以适用法律为准。

在部分欧洲经济区国家，数字同意的年龄门槛最高为 16 岁。若您未达到所在国家/地区要求的在线数据处理同意年龄，请在父母或监护人陪同下使用本应用，且未经其同意请勿直接联系我们。

加州居民

我们不会出售或共享个人信息用于跨情境行为广告。

加州居民可发送邮件至 1621829808@qq.com，了解我们（如有）从自愿联系中收集的个人信息类别，并可要求删除相关信息。

我们不会因您行使加州法律规定的隐私权利而歧视您。

儿童隐私

本应用在 App Store 的分级为 4+。我们不会通过本应用故意收集儿童的个人信息。

由于核心功能在本地运行且无需账号，在正常设备端使用过程中，我们不会有意收集包括儿童在内的任何人的个人信息。

请勿让儿童在未经父母或监护人同意的情况下通过邮件或 GitHub Issues 联系我们。 若您认为儿童在未经适当同意的情况下向我们提供了个人信息，请联系我们，我们将采取合理措施予以删除。

就美国用户而言，根据《儿童在线隐私保护法》（COPPA），我们不会故意收集 13 岁以下儿童的个人信息。

本政策的变更

我们可能会不时更新本隐私政策。最新版本将发布于本 URL，并更新生效日期与版本号。除适用法律另有规定外，您在变更后继续使用本应用，即表示接受更新后的政策。
